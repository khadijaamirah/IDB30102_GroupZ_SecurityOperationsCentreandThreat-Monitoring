# Expected Evaluation Metrics

The proposed Random Forest model will be evaluated against the Decision Tree baseline using the same testing conditions.

| Metric | Purpose |
|---|---|
| Accuracy | Measures the overall proportion of correctly classified traffic |
| Precision | Measures how accurately malicious predictions are identified |
| Recall | Measures the ability to identify actual malicious traffic |
| F1-score | Provides a balance between precision and recall |
| False Positive Rate (FPR) | Measures the proportion of benign traffic incorrectly identified as malicious |

## Comparison

The Random Forest model will be compared with the Decision Tree baseline using the same dataset, preprocessing procedures and testing data.

## Expected Success Condition

The proposed approach will be considered successful if Random Forest demonstrates improved detection performance, particularly through a higher F1-score while maintaining suitable precision and recall and reducing false positive detections.

## Note

No final numerical results are reported at this proposal stage. Actual metric values will be added after model testing.
