# Preliminary Source Code

This folder contains the preliminary technical work for the proposed machine learning-based cyber threat detection prototype.

The prototype uses the CIC-IDS2017 dataset to support binary classification of network traffic as benign or malicious.

The preliminary process includes:

1. Loading the CIC-IDS2017 dataset.
2. Cleaning and preprocessing the data.
3. Preparing the traffic labels.
4. Splitting the data into training and testing sets.
5. Training the machine learning models.
6. Evaluating the models using accuracy, precision, recall and F1-score.

Random Forest is used as the proposed machine learning model, while Decision Tree is used as the baseline model for comparison.

This source code represents preliminary technical work for the research proposal and is not a complete production SIEM system.
