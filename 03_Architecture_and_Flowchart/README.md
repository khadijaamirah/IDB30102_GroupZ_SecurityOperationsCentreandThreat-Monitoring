# Architecture and Flowchart

This folder contains the proposed architecture and system flowchart for the machine learning-based SIEM cyber threat detection prototype.

## Proposed Architecture

The proposed architecture shows how the CIC-IDS2017 dataset is processed before being used by the machine learning model. The model classifies network traffic as benign or malicious, and the detection result is then sent to the SIEM environment for security monitoring and alert generation.

## Proposed Flowchart

The flowchart shows the overall process from data preprocessing, feature selection, model training and testing to threat classification and performance evaluation.
