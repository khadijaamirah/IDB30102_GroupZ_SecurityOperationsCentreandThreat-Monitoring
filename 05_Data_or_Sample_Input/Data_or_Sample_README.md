# Data / Sample Input

## Dataset
CIC-IDS2017

## Dataset Description
CIC-IDS2017 is a publicly available cybersecurity dataset containing normal and malicious network traffic. The dataset provides labelled network traffic data that can be used for machine learning-based cyber threat classification.

## Data Source

Canadian Institute for Cybersecurity (CIC), University of New Brunswick.
Official dataset page:
https://www.unb.ca/cic/datasets/ids-2017.html

## Intended Use
The dataset will be used to train and test the proposed Random Forest machine learning model for binary classification of network traffic as benign or malicious.

## Data Preparation
The selected data will undergo preprocessing and feature selection before being used for machine learning. The prepared data will be divided into training and testing subsets.

## Data Flow
CIC-IDS2017 Dataset → Data Preprocessing → Feature Selection → Training / Testing Data

## Purpose in the Research
The dataset provides the input data required to develop and evaluate the proposed machine learning-based cyber threat detection approach in a controlled SIEM environment.

## Note
The complete dataset is not uploaded to this repository. Users should obtain the dataset from its official source. The dataset will be used for academic and research purposes.
